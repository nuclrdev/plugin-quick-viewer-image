# 🖼️ Image Quick Viewer

A lightweight **Nuclr Commander** quick-view plugin for the image formats you use most often: **BMP**, **JPG**, and **PNG**.

It is designed for fast, built-in previewing with **no external native dependencies**. Open an image in quick view and see it immediately inside the preview panel.

## ✨ What it does

- ⚡ Opens common image files directly in Nuclr Commander quick view
- 🪶 Keeps the setup simple by relying on Java's built-in image loading
- 📐 Fits images into the preview area while preserving aspect ratio
- 🎯 Focuses on the everyday formats: **BMP**, **JPG**, and **PNG**

## 📦 Supported formats

This plugin is intended for:

- `*.bmp`
- `*.jpg`
- `*.png`
- `*.gif`

If you need broader image format support, use the **ImageMagick Bridge** plugin instead:

👉 https://github.com/nuclrdev/plugin-imagemagick-bridge

That plugin is the better fit for formats outside the simple built-in image workflow.

## 🛠️ Why this plugin exists

Not every image preview needs a heavyweight dependency chain. This plugin covers the basic formats quickly and cleanly, which makes it a good default choice when you just want fast previews for standard images.

For anything more specialized, the ImageMagick-based plugin is the right extension point.
